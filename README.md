# 🛒 ShopSphere – MERN Stack E-Commerce Platform

## Overview
ShopSphere is a full-stack e-commerce web application built using the MERN stack. Users can browse products, manage cart, place orders, and track purchases.

## Features

### Customer Features
- User Registration & Login (JWT Authentication)
- Product Browsing
- Search & Filter Products
- Add to Cart / Remove from Cart
- Order Placement

### Admin Features
- Product Management
- Inventory Management
- Order Management

## Tech Stack
- Frontend: React.js, Tailwind CSS, Redux Toolkit
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT

## Deployment
- Backend: Render
- Frontend: Vercel
- Database: MongoDB Atlas
