🛒 ShopSphere – MERN Stack E-Commerce Platform
📌 Overview

ShopSphere is a modern full-stack e-commerce web application built using the MERN stack.
It allows users to browse products, manage cart, place orders, and track purchases with secure authentication.

✨ Features
👤 Customer Features
User Registration & Login (JWT Authentication)
Product Browsing
Search & Filter Products
Add to Cart / Remove from Cart
Wishlist (optional)
Order Placement & Tracking
🛠 Admin Features
Add / Update / Delete Products
Inventory Management
Order Management
Basic Sales Overview

🧰 Tech Stack
Frontend
React.js
Tailwind CSS
Redux Toolkit
Backend
Node.js
Express.js
MongoDB (Mongoose)
Authentication
JWT (JSON Web Token)

⚙️ Environment Variables
Backend (.env)
PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key

🚀 Run Project Locally
1️⃣ Clone Repository
git clone https://github.com/Sobhangini14/Shopsphere-project.git
2️⃣ Backend Setup
cd server
npm install
npm start
3️⃣ Frontend Setup
cd client
npm install
npm start

🌍 Deployment
Backend: Render
Frontend: Vercel
Database: MongoDB Atlas
